# RiskFlow Dashboard

Build the complete frontend-only VFSim — Graph-Based Risk-Aware Filesystem Simulator exactly as specified. Use React + TypeScript + Tailwind, React Router, Lucide, Recharts, and React Flow. Create the professional dark research dashboard across all requested pages, reusable components, realistic filesystem/GNN mock data, loading/error/empty states, interactive demo transaction/crash/recovery flow, and a centralized mock API service structured for future FastAPI endpoints via VITE_API_BASE_URL. Do not use Supabase, do not implement filesystem logic or GNN in JavaScript, and make DEMO versus LIVE backend status unmistakable.
